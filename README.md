# Arcade Pong

A lightweight browser-based Pong game (player vs CPU) implemented with plain HTML5 Canvas and JavaScript.

## Run locally

Open `index.html` directly in a browser, or serve the directory:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Controls

- Move paddle: `W` / `S` or `↑` / `↓`
- Start / serve / restart: `Space`

## Rules

- First to 7 points wins.
- After each point, press `Space` to serve.
